# Otter: interactive demo

Click-through demo of **Otter**, the AI back office for financial advisor practices, built at the LPL Financial University Hackathon 2026.

**Try it:** https://alichaaraoui.github.io/otter-interactive/

Everything runs in your browser on fictional sample data (Harbor Point Wealth), with no backend. Upload one of the bundled sample documents and watch it go through the approval rules, release a held vendor with its W-9 and void check, approve bills, review a low-confidence receipt, check the payout reconciliation and ask Otter questions about the books.

The full version ran on AWS (Amplify, Cognito, API Gateway, Lambda, Step Functions, EventBridge, DynamoDB, S3 Object Lock, Textract and Claude on Amazon Bedrock).
